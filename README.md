# ShalatAI-Biometric-Motion-V2
App web dashboard shalatAI V2 dilengkapi dengan AI Engine canggih yang mampu mendeteksi 33 titik anatomi tubuh secara instan, fitur interaktif AI Audio Voice Feedback asisten suara koreksi otomatis jika gerakan salah, sistem interlock Anti-Cheat waktu tumakninah, serta pencatatan otomatis rapor hasil ibadah langsung ke database
